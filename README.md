# toolbooth-mcp
Remote MCP server at `https://toolbooth.io/mcp` with read-only, pay-per-call tools for agents: Solana token prices and RugCheck safety checks, wallets and holders, Jupiter swap quotes, DEX pairs, Solana DeFi and LST yields, prediction markets and perps data, paid in USDC on Solana via x402 or with prepaid credit.
